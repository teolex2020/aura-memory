# E64: can an AI's past reply be recovered by asking again, and does the model matter?

Status: **frozen 2026-10-08**, before any model call. **Test only.**

## Question

E35 showed what is lost when memory keeps only the user's words. Questions
about what the assistant said drop to 40%, against 95% with the whole
conversation. E56 recovered them from the journal (90%). But:
- the journal keeps 30 days;
- not every client writes replies to it (Claude Desktop and ChatGPT through
  MCP do not);
- people use several models.

The owner asks how likely it is that a reply can be **recovered without
storing it**, by asking a model the same question again. And does it matter
whether that model is the one that answered first?

## Data

LongMemEval-S: all 51 non-abstention `single-session-assistant` questions
whose evidence is an assistant turn (5 more have a user turn as evidence and
are left out). The dataset's assistant turns were written by a model that is
not one of ours. Regenerating them with ours is therefore the
**different-model** case.

## Part 1: accuracy on the real questions

The reader gets the evidence session with its date and the question. The
reader is `gemini-3.1-flash-lite`, and the official LongMemEval judge is
used (E35/E20).

| Arm | The session shows |
|---|---|
| A | the user's turns and the original assistant turns (what a journal keeps) |
| B | the user's turns only (memory of the user's words, as in E35) |
| C | the user's turns, and the evidence turn **regenerated** by `gemini-3.1-flash-lite` |
| D | the same, regenerated by `gemini-2.5-flash` (thinking off) |

**How a turn is regenerated.** The model gets the session's user turns up to
and including the one being answered, and replies as the assistant. Earlier
assistant turns are shown as "(reply not kept)". Temperature is 1, as in a
normal chat. One sample is taken.

Only the evidence turn is regenerated. This is a **best case**: in real use
nobody knows which reply will be asked about.

**Direct check.** A judge (`flash-lite`) is asked whether the reply contains
the gold answer's information: yes/no. This is applied to the original turn
and to each regenerated one.

## Part 2: same model vs different model

To test the same-model case, there has to be an original reply written by one
of our models. For each evidence turn, three replies are generated from the
same prompt as above:
- **O:** `flash-lite`, temperature 1, sample 1 (the "original");
- **S:** `flash-lite` again, temperature 1, sample 2 (the same model asked
  again);
- **M:** `gemini-2.5-flash`, temperature 1 (another model).

A judge (`flash-lite`) compares S with O, and M with O. It answers whether
they give the same **specific** content (names, numbers, items, steps):
`same` / `partly` / `different`.

## Hypotheses

| | Hypothesis |
|---|---|
| G1 | regeneration recovers little: acc(C) − acc(B) ≤ 0.5 × (acc(A) − acc(B)) |
| G2 | the model matters: S matches O as `same` at least 15 pp more often than M does |
| G3 | the gold detail survives regeneration in under half the cases: direct check < 50% for C and D |

The hypotheses are reported, not used as ship decisions.
