# Зовнішні бенчмарки замість тижнів власного тестування (2026-10-02)

Рішення власника: не чекати 2–3 тижні живого використання, а перевіряти на
публічних даних. Агент перевірив кандидатів за офіційними сторінками
(картки Hugging Face, GitHub, arXiv). Позначене «?» не підтверджено.

## Відкриті питання і найкращі набори даних

| Питання | Набір | Що це | Розмір | Ліцензія | Чим корисний |
|---|---|---|---|---|---|
| Реальні сесії, повтори, виправлення, коди виходу | **SWE-chat** (COLM 2026) | справжні сесії Claude Code / Codex / Gemini CLI / Cursor з публічних репозиторіїв: інструменти, коди виходу, позначені «заперечення» користувача, `user_id` у різних сесіях | 5,8–18 тис. сесій, 2,7 млн рядків, ГБ ? | ODC-BY, **доступ після прийняття умов** | Найближчий до продукту. Замінює наш тест на живих даних |
| Сигнали наслідків у агентів | **nebius/SWE-rebench-openhands-trajectories** | 67 тис. запусків OpenHands: `resolved`, `exit_status`, виводи інструментів | 2,08 ГБ | CC-BY-4.0 | Чи придатні коди виходу і успіх задачі як сигнал цінності для пам'яті агента |
| Пам'ять, що вчиться з успіху/невдачі | **StreamBench** (NeurIPS 2024) | потоки задач (SQL, код, інструменти, діагностика, QA) з відомою правильністю після кожної | 17 МБ + бази SQL (~1–2 ГБ ?) | Apache-2.0 | Мережа цінності на зовсім іншому типі задач. Повністю офлайн |
| Контрольні факти | **PrefEval** (ICLR 2025 oral) | 3 000 пар «вподобання → запит», що спокушає порушити, з відволіканням до 300 реплік. 4 типи порушень | < 5 МБ | CC-BY-4.0 | Точність перевіряльника порушень. GPT-4o за 300 реплік: 0,23 |
| Забування і застарілі факти | **MemoryAgentBench** (ICLR 2026) | поступове надходження; розділ розв'язання конфліктів (FactConsolidation) | 77 МБ | MIT | Найслабше місце всіх систем — заміна застарілого факту |
| Справжні багатосесійні логи (загальні користувачі) | WildChat-4.8M | справжні розмови ChatGPT; `hashed_ip` + user-agent + час | кілька ГБ ? | ODC-BY | Повтори тривкої інформації в загальних користувачів. Зв'язок користувачів неточний |

Не підходять для дешевого офлайн-запуску: ReasoningBank, Agent Workflow Memory
на WebArena, Memento (потрібні живі середовища). LMSYS-Chat-1M не дає
пов'язати користувачів.

## Запропоновані експерименти

| № | Набір | Питання | Ціна API (оцінка) |
|---|---|---|---|
| E42 | PrefEval | Чи ловить перевіряльник контрольних фактів (E30) порушення вподобань на чужих даних, з відволіканням до 300 реплік? | ~$1–3 |
| E43 | SWE-chat | Що з реальних сесій розробників повторюється в різних сесіях? Чи передбачають «заперечення» користувача й коди виходу, які записи цінні? | ~$1–3 |
| E44 | StreamBench | Чи вчиться мережа цінності з правильності задач у потоці, поза розмовами? | ~$2–4 |
| E45 | nebius OpenHands | Чи є коди виходу і успіх задачі придатним сигналом наслідків для пам'яті агента? | локально / ~$1 |
| E46 | MemoryAgentBench | Заміна застарілих фактів. Порівняння з опублікованими результатами | ~$1–2 |
