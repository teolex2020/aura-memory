## Межі

- Події згенеровано у форматі Claude Code, але сам Claude Code не запускався
  (CLI `claude` на цій машині не встановлено). Форми відповідей інструментів
  (WebFetch, MCP) — за документацією та відомими прикладами; джерела
  розходяться навіть у назві поля запиту, тому адаптер приймає всі варіанти.
  Перевірка на справжніх подіях — щоденне використання.
- Прийом у продукті робить Python MCP-сервер (перед кожним викликом
  інструмента) або сам hook, якщо пам'ять вільна. Rust MCP-сервер і HTTP-сервер
  скриньку поки не читають.
- Як і в E16, пошук з embeddings `bge-m3`; Python MCP-сервер за замовчуванням
  embeddings не задає.
- Скринька — звичайна папка: локальний процес із правами користувача може
  підкласти туди подію. Це той самий рівень довіри, що й до самої папки пам'яті.
